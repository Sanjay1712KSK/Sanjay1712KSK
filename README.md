## 🚀 Featured Projects

### 🎬 AI Upscaler Studio — *Ayan Crafts*
> **Local, NVIDIA-accelerated AI video upscaling and frame interpolation, shipped as a one-click desktop app.**

- **Stack:** Python · PyTorch (CUDA FP16) · Real-ESRGAN · RIFE v4.25 · PySide6 · FFmpeg / NVENC
- **Why it matters:** Packages research-grade models into a Windows installer and Ubuntu packages—no Python environment hell, no CUDA toolkit battles.
- **Validated on:** NVIDIA RTX 4070 SUPER 12 GB and RTX 4050 Laptop 6 GB.
- **Impact:** 1080p30 → 1440p60 in a single desktop workflow.

[![Repo](https://img.shields.io/badge/Repository-AI--Video--Upscaler-181717?style=flat-square&logo=github)](https://github.com/Ayan-Crafts/AI-Video-Upscaler--Powered-by-Nvidia)

- **Why it matters:** Turns hours of sports video into training-ready datasets without manual drudgery.
